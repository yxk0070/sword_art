# 江湖路远 (Sword Art)

一款基于 React 构建的文字武侠对战游戏。

## 游戏特色

- **自由养成**：从“小虾米”开始，你可以自由选择你的初始入门内功、轻功与招式套路。
- **武学收集**：击败各路武林高手，即可获得他们身上的绝学。游戏包含 16 套武功（共 48 招）、5 种内功心法和 5 种轻功身法，分为“入门”、“进阶”、“绝学”三个品阶。
- **排兵布阵**：战斗采用“12 息”时间线系统。你需要根据敌人的出招意图（起、承、转、合、收、结），合理安排自己的招式顺序。
- **克制机制**：招式拥有“攻击”与“防御”属性，且分为“强势”与“弱点”部位。攻击敌方弱点可造成【弱点击破】的巨额伤害。
- **神功特效**：部分绝学招式附带特殊的战斗效果，如【破甲】（无视防御）、【吸血】（恢复生命）、【反震】（反弹伤害）等。

## 本地运行

1. 确保你已安装了 Node.js。
2. 进入 `frontend` 目录：
   ```bash
   cd frontend
   ```
3. 安装依赖：
   ```bash
   npm install
   ```
4. 启动开发服务器：
   ```bash
   npm run dev
   ```
5. 打开浏览器访问终端输出的本地地址（如 `http://localhost:5173/`）。

## 游戏重置

如果你想重新体验从零开始的乐趣，或者选择不同的初始武功路线：

- 点击主界面右上角的【大侠面板】
- 点击左上角的【重新开始游戏】按钮即可清空进度并返回创建角色页面。
